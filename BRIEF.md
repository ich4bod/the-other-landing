# The Other Landing
Zach asked for something genuinely scary for human beings in October. Make an original, short domestic horror story, not a Halloween-themed puzzle. Its threat is a familiar apartment rearranging itself around the listener, and a visitor that reproduces the player's own knocking rhythm. Fear is an artistic aim, not something an automated test can prove.

## Model (first card)
DOM-free ESM public/model.mjs exports create(), reduce(state,event). create returns {started:false,scene:0,paused:false,ended:false,knocks:[]}. No timestamps or randomness in create. Events are {type:'begin'}, {type:'advance'}, {type:'open'}, {type:'pause'}, {type:'resume'}, {type:'knock',at:nonnegative finite milliseconds}, {type:'restart'}. Unknown events and invalid/blocked actions return a fresh equal state. Never mutate input; every returned knocks array is separate. begin only works when not started. advance only when started,!paused,!ended: scenes0..7 increment by1; arriving8 sets ended:true. open only at scene6 sends9 and ended:true. pause only when started and not ended; resume clears paused. knock only started,!paused,!ended at scene6: strictly increasing timestamps, retain LAST6; invalid/nonincreasing values ignored. restart always resets create. Ending scenes never advance or knock. No time-driven narrative changes: reading pace belongs to the player.

## Sound (stage4)
Web Audio synthesized locally. No fetches or clips. Sound only after explicit #sound click, never auto. MasterGain0.15, per-source peak<=0.35, no loud jumps. A dark lowpass hum uses55Hz sine gain0.025. Knocks are bandpassed deterministic noise bursts90ms, attack5ms, exponential decay to0.001; cutoff750Hz/Q0.7, per-burst gain0.25. Story knocks at scene0 and2 offsets[0,320,640]ms; pan-.6 at0,+.6 at2. Cloth uses lowpass noise gain0.04; breathing uses filtered noise with4000ms slow gain envelope peak0.025. Scene3 removes hum, scene5 adds breath. Scene7 reprises user offsets from stage5 with pan+0.6; fallback[0,320,640]. No speech synthesis, external voices, infrasound claims, binaural-health claims or redlining. Dispose/stop scheduled sources on scene change, pause, sound off, restart and hidden tab. One AudioContext reused. Audio errors set unavailable and print exact controls.audioError in #audio-status; don't block story.

## Knock imitation (stage5)
At scene6 clicking/tapping #knock or Enter/Space native button produces knock with performance.now timestamp, model retainslast6. echoOffsets computes retained timestamps relative to first. Record UI taps even when sound off. After each tap cancel earlier pending echo; after900ms quiet play one echo of the WHOLE retained rhythm with pan-.6 and softer amplitude0.6 of original. If next scene/pause/off/hidden/restart happens first, cancel pending echo. When scene7 reached, reprise same offsets once, even if >900ms. Render an amber ring around peephole per echo burst; no flashing full screen. #caption at scene6 after at least1tap becomes "Your rhythm returns from the other side." (authored additional copy). All other captions fixture exact. Disabled paused taps never record. No microphone or voice recording.
